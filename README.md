# Lost & Found System

## Run
    pip install flask
    python app.py
Open http://127.0.0.1:5000

## Features
- Report lost/found items, with optional photo upload
- Search and filter, item detail page, possible matches
- Admin login (/login, default password: admin123 - change it in app.py)
- Admin dashboard (/admin): stats + table of all items
- Admin-only: mark returned, delete
- Dark mode toggle
